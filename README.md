# NutriAI 🥗

**NutriAI** is a personalized nutrition and wellness platform that combines user biometrics, lifestyle data, metabolic science, and AI-powered recommendations.

---

## 🚀 Features

- **Modern Responsive Dashboard**: Clean emerald-green and crisp white aesthetic designed for desktop, tablet, and mobile.
- **Biometrics & Metabolic Engine**: Mifflin-St Jeor BMR, TDEE, and personalized Macronutrient targets (Protein, Carbs, Fats, Water, Fiber).
- **7-Day Dynamic Meal Planner**: Tailored recipe schedules with ingredient breakdown and prep steps.
- **Automated Smart Grocery List**: One-click consolidated shopping list generator categorized by grocery aisles.
- **Interactive Nutrition & Food Tracker**: Real-time caloric and macronutrient budget tracking with pre-loaded food database search and quick custom food logging.
- **Wellness & Habit Streaks**: Hydration tracker (+250ml / +500ml quick logging), sleep/recovery scores, and body weight trajectory.
- **Health-Tech Previews (Demo Data)**:
  - 🧬 Biomarkers & Laboratory Panels (Cardiometabolic, HbA1c, Vitamin D3, Lipids)
  - 🔬 Genetic Insights & Nutrigenomics (Caffeine clearance, Lactose tolerance, Omega-3 conversion)
  - ✨ NutriAI Smart Recommendations Engine (Protein pacing, carb timing around workouts)
  - 📑 Metabolic Health & Weekly Digest Reports (Export Sample PDF)
  - 👩‍⚕️ Specialist Network (Board-certified sports dietitians and clinical nutritionists)

---

## 💻 Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Design System, CSS Variables, Responsive Grid & Flexbox)
- **Logic**: Vanilla JavaScript (ES6+ modular architecture, Native HTML5 Canvas Charts)
- **Zero Build Step**: Runs directly in any modern browser without npm dependencies.

---

## 🏃‍♂️ How to Run Locally

You can serve the frontend using any static file server, for example Python's built-in HTTP server:

```bash
# Start a local server in the project directory
python -m http.server 8000

# Open in your browser:
# http://localhost:8000/frontend/
```

Or simply open `frontend/index.html` directly in your browser.
